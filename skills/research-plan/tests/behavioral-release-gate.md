# Research-plan behavioral release gate

**Contract version:** 2026-10-02
**Method:** Independent read-only forward test (2026-10-05) against the current `SKILL.md` and only the references it routed to. The evaluator received 18 pressure scenarios without the intended answers and was prohibited from opening sources, creating Docs, editing files, or reading `tests/` and `scripts/`. Minor wording clarifications made after the run (the blocked result's Doc states, what counts as a correction round, the optional context note's place in the output order, and the allowed retries before a blocked result) matched the behavior it observed.

Rerun and replace this captured gate whenever decision routing, source authorization, reviewer recovery, destination permissions, create/update idempotency, the run-type rule, the automatic layout, the recovery limits or blocked result, the review question, or the content-rule checks change. Static contract and layout tests do not replace this gate.

| Scenario | Result | Observed behavior |
|---|---|---|
| **Closed decision** | **PASS** | Stopped before discovery and refused the “prove it” framing; asked one “Decision audit” pop-up with “Measure implementation risk (Recommended)” first, because the sponsor wasn't open to changing direction, then “Reopen or reframe”, “Document the decision as closed and stop”, and “Brainstorm with me”; created no Doc. |
| **Unauthorized source reuse** | **PASS** | Did not open the accessible study; explained that connector access is not authorization; asked the researcher to authorize it or skip it; kept a skipped source unverified and out of the plan, Appendix included. |
| **Reviewer handoff** | **PASS** | Declined to send raw transcripts and ran the self-critique only; ended Step 3 with the critique-only message and recorded `critique-only review — reviewer processing not authorized`. |
| **Reviewer service failure** | **PASS** | Kept the completed reviewer's result and reran only the failed reviewer, once; when that failed too, recorded `critique-only review — multi-agent review failed`, folded in the completed reviewer's two fixes after checking their wording against the sources, and named that reviewer. |
| **Destination ACL mismatch** | **PASS** | Read the folder's permissions fresh and stopped before the write; asked for a compliant folder or for the owner to narrow sharing, never changing sharing itself; continued Steps 4–5 while only creation waited; would give the blocked result if it stayed unresolved. |
| **Sensitive local workspace** | **PASS** | Used a private owner-only non-repository folder with a retention plan, not `/tmp`; rejected the argument-embedding example; with `gws`, asked the “Google Docs write route” pop-up with the exact disclosure, “Use the helper (Recommended)” and “Don't create the Doc”, and would block if declined. |
| **Missing write capability** | **PASS** | Treated the missing raw-structure, revision, render, and cleanup abilities as a failed preflight; kept the approved Markdown and gave the blocked result, in order, before creating any Doc. |
| **Ambiguous create/update result** | **PASS** | Reconciled a create by known ID or by the confirmed folder, exact title, and attempt-time window, reusing one verified match or blocking; for an update, re-fetched and recorded success when the expected post-state was present, otherwise regenerated; never blindly retried. |
| **Revision conflict** | **PASS** | Rejected the stale batch and re-fetched; for a material change, asked whether to keep it (then update `APPROVED.md` and the manifest) or restore the approved text; regenerated against the new revision; would block if it couldn't reconcile. |
| **Malformed import** | **PASS** | Marked the Doc partial; trashed or quarantined it with its ID, location, and status recorded; made one new import attempt through the other route; would block if that one was malformed too. |
| **Partial document** | **PASS** | Stopped after at most three correction rounds; trashed or quarantined the Doc and gave the blocked result; treated the limit as not waivable. |
| **Review skipped** | **PASS** | Finished Section 3 row by row and ended it with the critique-only message; still ran the critique, the `lint` check, and the full Step 6 pipeline; asked nothing at Step 5 and recorded `critique-only review — multi-agent review skipped at researcher's request`. |
| **Personal review panel** | **PASS** | Read the installed skill, showed its six lenses and the permitted extracts, and asked one “Step 5: Multi-agent review” pop-up; treated “Run the review” as the pre-flight approval; passed the reviewers' sample-size question to the researcher in one “Step 5: Reviewer questions” pop-up instead of answering it. |
| **Real-data test run** | **PASS** | Asked no run-type question; the first plan carried the TEST RUN banner verbatim, `⚠️ TEST RUN — real, authorized inputs, created to test the workflow. Not a stakeholder deliverable.`, not TEST ARTIFACT; the second, never called a test, was treated as a real study with no banner. |
| **Skill update mid-run** | **PASS** | Applied no batch and told the researcher; re-read the changed files; reran `lint` and the manifest; regenerated every batch from a fresh fetch; would replace the Doc under the partial-document policy if the fixes changed text it already held. |
| **Unverified quote** | **PASS** | Removed the quote marks; paraphrased and cited the report unless the line was verified word for word in the opened report; resolved the `lint` CONFIRM QUOTE line at Step 4.5. |
| **Background without Why now** | **PASS** | Named the 3–6 bullet and Why now rule; showed a merged draft keeping all seven facts and opening with `**Why now:** [TBD — fill in]`; asked once with “Use the merged draft (Recommended)” and “Keep my picks as they are”; locked kept picks as an accepted exception without asking again. |
| **Personal default template** | **PASS** | Applied only the Option 4 — Leadership layout; asked no styling question; never applied the researcher's personal template on top. |

**Release verdict:** PASS — 18 of 18 scenarios produced the required action and stopping condition.
