# Add-On Decision Log Template

Format for Output-structure component 7 (Add-on register) and the "Add-on absorption discipline" section in SKILL.md. Use this whenever a stakeholder proposes a new question or task after the plan is already in motion.

## Classification criteria

| Classification | Use when | What happens next |
|---|---|---|
| **(a) Absorb** | The add-on fits the existing instrument and timing — doesn't push the session past the Q5 budget, doesn't need a different sample or stimulus | Fold into the task list / synthesis tail this round; re-check Time budgeting after adding it |
| **(b) Hold** | The add-on is good but needs a different instrument, recipe/content set, or sample than this study already has — or would blow the time budget | Log it with a future home (a follow-up round, a different study, or a specific project's backlog) so it isn't silently dropped |
| **(c) Reject** | Duplicates an existing question, or doesn't serve the research question from Intake Q1 | Log the rationale so the requester sees it was considered, not ignored |

## Log format

Copy this table per study. One row per add-on, in the order proposed.

| # | Proposed by | Question/task proposed | Classification | Rationale | Future home (if Hold) |
|---|---|---|---|---|---|
| 1 | [name] | [one-line description] | Absorb / Hold / Reject | [why] | [n/a, or where it goes] |

If no add-ons have surfaced yet for this study, still include the section in the plan output — write:

```
None this round.
```

Don't omit the section entirely — the 8-component output structure stays constant whether or not an add-on was actually proposed, so a reviewer scanning for this component finds an explicit "none" rather than wondering if it was skipped.

## Notes

- Rationale is required even for Absorb — "fits the instrument, doesn't affect timing" is enough, but a blank rationale cell isn't acceptable just because the answer was easy.
- A Hold with no future home is effectively a silent Reject — always name where it goes (even if the answer is "no home yet, flagged for the requester to decide").
- If an Absorb changes the task count or session length, re-run the Time budgeting check (SKILL.md) before finalizing — an add-on absorbed without that check is how studies quietly run long.
